      - **Запрещены пояснения в скобках**: кнопки и группы называть просто и чисто (`«Создать элемент»`, а не `«Создать элемент (пользовательский ввод)»`).
      - **Запрещены кальки нейросетей**: не писать в предупреждениях `«Пожалуйста, выберите...»`. Писать: `«Выберите документ!»` или `«Не выбран документ!»`.
      - **Естественный русский порядок слов**: `«Новый склад»`, а не `«Склад новый»`.
      - **Единый экран вместо лишних закладок**: не прятать табличные части в закладки `<Pages>` («Основное» / «Материалы»), если в методичке показан плоский экран.
      - **Группировка кнопок**: не оставлять плоские серые столбцы из 7+ кнопок без логической структуры.
      - **Интерактивный пересчет на клиенте (`ПриИзменении`)**: у колонок табличной части (`Количество`, `Цена`) обязательно должен быть привязан обработчик `ПриИзменении` для мгновенного расчета `Сумма = Количество * Цена` при вводе в режиме 1С:Предприятие.
      - **Запрет периодической нумерации (`Year`) при однопараметрическом `НайтиПоНомеру(Номер)`**: если в коде обработки используется `Документы.<Имя>.НайтиПоНомеру(Номер)` без второго параметра `ДатаИнтервала`, у документа в XML обязательно должно стоять `<NumberPeriodicity>Nonperiodical</NumberPeriodicity>` (иначе поиск ищет в `0001` году, возвращает `ПустаяСсылка`, и кнопки копирования/отмены проведения/изменения молча ничего не делают).
      - **Обязательный визуальный отклик кнопок в обработках (`Сообщить` + `ОповеститьОбИзменении`)**: любая кнопка обработки, которая программно создает, копирует или меняет документ в фоне, обязана выводить `Сообщить(...)` и на клиенте вызывать `ОповеститьОбИзменении(ДокСсылка)`, чтобы пользователь сразу видел результат и открытая форма списка обновлялась на экране автоматически. Все входные поля на форме располагать строго выше кнопки действия.

## Risk Sensitivities

- Secrets, API keys, passwords and customer data must never be saved in notes or public places.
- Note any project-specific boundaries (e.g. public demos require hardened auth; internal vs external communication roles — see [[01_Index/People]]).

## How Agents Should Work With Денис

- Start with the concrete conclusion, then the reasoning and the next step.
- When choosing between options, give a recommendation, not a neutral list.
- If the task is feasible, carry it to the end: changes, verification, context update.
- If data is missing, first look in the workspace/code/files; ask only when no safe hypothesis exists.
- After a major task, update the workspace per [[70_Resources/Agent_Context_Automation]] and [[70_Resources/AI_Context_Quality_Guide]].
