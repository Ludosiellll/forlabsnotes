# Стандарт оформления отчетов по лабораторным работам

## Общие правила нумерации заданий

- В разделе «Результаты выполнения работы:» задания всегда нумеруются строго сквозной нумерацией: **Задание 1. <Текст задания>**, **Задание 2. <Текст задания>** и т.д.
- **Дополнительные задания считаются полноценными продолжениями основных заданий**: категорически запрещено писать «Дополнительное задание 1.», «Задание для самостоятельного выполнения:» или объединять доп. задания в один пункт. Если в работе 5 основных заданий и 3 дополнительных, то в отчёте (и в списке `Задание:` в шапке, и в разделе `Результаты выполнения работы:`) должно быть ровно **8 сквозных заданий** (`Задание 1.` … `Задание 8.`).
- **Выбор вариантов заданий**:
  - По предмету **«Компьютерные сети»** всегда выбирается **Вариант 2**.
  - По **другим предметам** (1С:Предприятие, ССП и т.д.) всегда выбирается **Вариант 14**.

## Отказ от таблиц по умолчанию (Лаконичность отчётов)

1. **По умолчанию все отчёты составляются БЕЗ ТАБЛИЦ** и без лишней детализации. Не нужно добавлять сводные таблицы реквизитов, свойств или параметров в каждое задание.
2. Каждое задание оформляется кратко: 1–2 предложения (или короткий список через `- `), листинг кода (`Листинг N`) и скриншот (`Рисунок N`).
3. Таблицы с разделителем табуляции и строкой `(таблица из N столбцов и M строк)` используются только если Денис сам явно попросил добавить таблицу.

## Правила оформления кода, листингов и рисунков

1. **Единое правило подписи из верхнего предложения-подводки**:
   - Название после тире в `Рисунок N – ...` или `Листинг N – ...` всегда формируется **напрямую из подлежащего/темы верхнего предложения-подводки** (текста перед словами `представлен(о/а/ы) на рисунке N` / `в листинге N`).
   - Пример для рисунка:
     - Подводка: `Окно среды разработки VS Code с исходным кодом проекта и встроенным терминалом представлено на рисунке 3` (без точки в конце).
     - Скриншот.
     - Подпись: `Рисунок 3 – Окно среды разработки VS Code с исходным кодом проекта` (без точки в конце).
   - Пример для листинга:
     - Подводка: `Исходный код программы работы с двумерным массивом 5 х 5 представлен в листинге 2` (без точки в конце).
     - Заголовок листинга: `Листинг 2 – Исходный код программы работы с двумерным массивом 5 х 5` (без точки в конце).
     - Исходный код.
2. Запрещено придумывать для подписи рисунка или листинга совершенно другую формулировку, не совпадающую с верхним предложением-подводкой.

## Формат выдачи отчета в чат (СТРОГОЕ ПРАВИЛО)

- Готовый отчет **ВСЕГДА** выдается целиком внутри одного блока кода ```text ... ``` (чистый неформатированный текст).
- **КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО** выводить отчет в чат обычным markdown (с `#`, `**` и таблицами через `|`), так как это ломает форматирование и таблицы при копировании в Microsoft Word.
- Текст должен копироваться целиком одной кнопкой «Copy» из блока кода.

## Шапка отчета

```text
Лабораторная работа №...
Номер учебной группы: РС02-23
Дата выполнения работы: ...
Тема: ...
Цель: ...
Оснащение: ...

Выполнение заданий
```

## Форматирование списков и текста для Word

1. **Перечисления и списки через дефис `-`**:
   - Слово после дефиса всегда пишется **строго с маленькой буквы**: `- склад ...`.
   - В конце каждого промежуточного пункта перечисления ставится точка с запятой `;`: `- склад (тип данных «СправочникСсылка.Склады»);`.
   - В конце последнего пункта перечисления ставится точка `.`: `- комментарий (тип данных «Строка», длина 50).`.
2. **Без точки в конце ссылки**: в предложениях-подводках к рисункам, листингам и таблицам точка в конце НЕ ставится.
3. **Без точки в подписи**: Рисунок N – Название / Листинг N – Название / Таблица N – Название.
4. **Контрольные вопросы (ТОЛЬКО если они есть в задании, МАКСИМАЛЬНО КРАТКО)**:
   - **Запрещено придумывать контрольные вопросы от себя!** Если Денис не давал список контрольных вопросов в задании, раздел «Контрольные вопросы» в отчёт **не включается** (после последнего задания сразу следует `Вывод: ...`).
   - **Максимальная краткость ответов**: ответы пишутся от руки в тетрадь, поэтому каждый `Ответ:` должен быть ультракратким (5–15 слов, 1 простое предложение или короткая фраза по самой сути, без повторения вопроса и без воды).
   - Если контрольные вопросы даны в задании — оформлять строго по формату:
   ```text
   Ответы на контрольные вопросы:

   1. Вопрос 1
   Ответ: максимально краткий ответ по сути.

   2. Вопрос 2
   Ответ: максимально краткий ответ по сути.
   ```
5. **Формулировка Вывода**:
   - Вывод пишется в самом конце документа, берется строго из Цели и формулируется в прошедшем времени от 1-го лица простым преобразованием глагола (например, «Цель: Исследовать...» → «Вывод: Исследовал...»).
   - Категорически запрещено добавлять отсебятину, подробности заданий или перечисления. Только одна точная фраза по формуле цели.
