## Ключевые понятия и параметры ЛР18

- Protocol Data Unit (PDU):
  - Модель OSI: кадр (Канальный уровень, Ethernet II) -> пакет (Сетевой уровень, IPv4) -> сегмент/датаграмма (Транспортный уровень, TCP/UDP) -> данные/сообщение (Прикладной уровень, HTTP, DNS).
  - Инкапсуляция и деинкапсуляция: добавление заголовков при движении вниз по стеку и снятие при обработке на принимающей стороне.
- Фильтрация в Wireshark (Display Filters):
  - Зеленая подсветка поля ввода при корректном синтаксисе (`tcp`, `udp`, `http`).
  - Логические операторы (`&&`, `||`, `!`).
  - Разбор структуры полей заголовков TCP (порты, Seq, Ack, Flags, Window size, Checksum), UDP (порты, длина, Checksum), HTTP (метод GET, Status 200 OK, заголовки Host, Content-Type, Content-Length).
- Файлы и материалы: папка `ЛР18_Файлы/`, отчет `report_lr18.txt`, таблицы `pdu_tables.txt`, скриншоты `screen_1` – `screen_5`, генератор трафика `traffic_generator.py`.


- Виртуальные сети (VLAN, IEEE 802.1Q):
  - Access-порты: привязка к одному VLAN, передача нетегированного трафика к конечным узлам.
  - Trunk-порты: мультиплексирование трафика нескольких VLAN по одной линии связи с тегированием dot1q.
  - Протокол DTP (Dynamic Trunk Protocol): режимы auto, desirable, nonegotiate.
  - Межсетевая маршрутизация (Inter-VLAN Routing):
    - L3-коммутатор (SVI `interface VlanX`, `ip routing`, `no switchport`).
    - Router-on-a-Stick (подинтерфейсы маршрутизатора `fa0/0.X` с `encapsulation dot1q X`).
- Материалы: папка `ЛР17_Файлы/`, схема [[scheme_vlan_topology.png]], скрипты `cisco_vlan_configs.txt`, таблица `vlan_addressing_table.txt`, отчет `report_lr17.txt`.

## Ключевые понятия и параметры ЛР16

- Протокол FTP (File Transfer Protocol, RFC 959):
  - Канал управления (FTP Control) — TCP порт 21 (команды USER, PASS, PWD, CWD, RETR, STOR, QUIT).
  - Канал данных (FTP Data) — TCP порт 20 в активном режиме (PORT) или динамический порт в пассивном режиме (PASV).
  - Отсутствие шифрования: логины, пароли и данные передаются открытым текстом.
- Анализ в Wireshark:
  - Пакеты ICMP при выполнении ping 10.0.0.11.
  - Аутентификация FTP (команды USER и PASS, ответы 331, 230).
  - Выполнение команды get file.zip (команда RETR, ответ 150).
  - Передача блоков полезной нагрузки по каналу FTP-DATA (ответ 226 Transfer complete).
