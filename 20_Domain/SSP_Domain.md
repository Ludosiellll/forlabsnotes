# Современные системы программирования (ССП)

## О дисциплине

Дисциплина посвящена изучению архитектуры, компонентов и функциональных возможностей современных систем программирования, сред разработки (IDE), компиляторов, отладчиков, систем сборки и профилирования.

## Материалы и результаты (Лаб №8)

- Вариант 14 по журналу (Приложение А: двумерный массив 5 х 5, функция заполнения случайными числами от 30 до 60, функции поиска максимального и минимального элементов).
- Задание 1: программа `task1_stairs_and_square.go` (лесенка из `n` ступенек вида `1 / 2 2 / 3 3 3` с использованием двумерного среза `stairs` и вычисление квадрата числа `n^2 = 1 + 3 + 5 + ... + (2*n - 1)` с пошаговым выводом текущей суммы).
- Задание 2: программа `task2_matrix5x5.go` (функции `fillMatrix()`, `findMax()`, `findMin()` для массива `[5][5]int`).
- Скриншоты: `screen_task1_stairs_square.png`, `screen_task2_matrix5x5.png`, `screen_vscode_lr8.png`.
- Папка работы: `ЛР8_ССП_Файлы/`.
- Отчет: `report_lr8_ssp.txt`, `report_lr8_ssp.docx` (полный стандарт РС02-23, без таблиц, 8 контрольных вопросов, 100% PASS валидатора).

## Ключевые понятия и IDE (Лаб №1)

- Компоненты СП: IDE, язык программирования, транслятор (компилятор/интерпретатор), редактор кода, компоновщик (линкер), отладчик, библиотеки/фреймворки, документация.
- Классификация СП: по уровню абстракции (машинно-ориентированные vs машинно-независимые), по способу трансляции (компилируемые, интерпретируемые, гибридные), по парадигме (ООП, функциональные, процедурные).
- Анализируемые IDE: Microsoft Visual Studio, Eclipse, Xcode, IntelliJ IDEA, Apache NetBeans.
