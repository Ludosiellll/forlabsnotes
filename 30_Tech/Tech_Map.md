# Tech Map

Техническая карта рабочего окружения проекта «Лабораторные работы по 1С».

## 1. Платформа 1С:Предприятие 8.3
- **Версия**: 8.3.27.1508 (учебная версия технологической платформы).
- **Расположение исполняемых файлов**:
  - `D:\1c_app\8.3.27.1508\bin\1cv8t.exe` (толстый клиент и пакетный режим / Конфигуратор; путь через ASCII-junction `D:\1c_app` во избежание проблем с CP866).
  - `D:\1c_app\8.3.27.1508\bin\1cv8ct.exe` (тонкий клиент).
- **Конфигурационный файл платформы**:
  - `D:\1c_app\8.3.27.1508\bin\conf\conf.cfg`
  - Настройка безопасности: `DisableUnsafeActionProtection=.*` (блокирует предупреждения безопасности при пакетном запуске внешних обработок).

## 2. Инструментарий автоматизации
- **Скрипты пакетных операций**: `.agents/skills/1c-batch/scripts/`
  - `run-enterprise.ps1` — неблокирующий запуск предприятия.
  - `run-designer.ps1` — запуск конфигуратора.
  - `build-epf.ps1` / `dump-epf.ps1` — сборка/разборка внешних обработок из XML.
  - `load-config.ps1` / `dump-config.ps1` — сборка/выгрузка метаданных конфигурации.
- **Файл привязки dev-базы**: `d:\1с лабы\.1c-devbase.ps1` (UTF-8 с BOM).
