# Регламент автоматизации и сдачи лабораторных работ по 1С

## Контекст
В ходе выполнения ЛР3 по 1С возникли задержки: поиск путей к платформе 1С, блокировка автоматического заполнения базы диалогом безопасности платформы 1С и передача студенту пустой базы без предварительной проверки фактического наличия данных в таблицах.

## Решение
1. Зафиксировать все пути к платформе (`D:\1c_app\8.3.27.1508\bin\1cv8t.exe` через безопасный ASCII-junction) и отключение проверки опасных действий (`DisableUnsafeActionProtection=.*` в `conf.cfg`).
2. Внедрить обязательный регламент [[70_Resources/Procedure_1C_Lab_Execution]] в матрицу навыков [[70_Resources/Skill_Router_Matrix]].
3. Для каждой 1С-лабораторной агент обязан:
   - Создавать батники запуска в 1 клик (`Запуск_1С_Предприятие.bat` и `Запуск_Конфигуратор.bat`).
   - Автоматически и верифицированно наполнять базу данными перед сдачей.
   - Выгружать актуальный `.dt` только после заполнения данными.
   - Предоставлять студенту пошаговую инструкцию по снятию скриншотов.

## Последствия
Исключаются повторные сбои, пустые базы данных и рутина с ручным вводом команд студентом.
