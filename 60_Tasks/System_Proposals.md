# System Proposals

Ideas, problems and rough edges concerning the **OS layer itself** — protocol, router, scripts, checks, evals, entry points. Agents: when a system change seems needed, record it HERE (project work still goes to [[60_Tasks/Task_Log]]) and keep working within the current system.

This file is included **verbatim** in the feedback report (`tools/make_feedback_report.ps1`) that the user may send to the template author. Therefore: write entries so they make sense without project context, and NEVER include secrets, people's names, or private project details — describe the system problem, not your project.
