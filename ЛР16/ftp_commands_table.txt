Основные команды протокола FTP:
Команда	Назначение
USER	Имя пользователя для аутентификации на сервере
PASS	Пароль пользователя для входа на сервер
PWD	Отображение текущего рабочего каталога на сервере
CWD	Смена текущего каталога на сервере
CDUP	Переход в родительский каталог
LIST	Получение подробного списка файлов и папок в каталоге
RETR	Скачивание (загрузка) указанного файла с сервера клиенту
STOR	Закачка (выгрузка) файла с клиента на сервер
DELE	Удаление указанного файла на сервере
MKD	Создание нового каталога на сервере
RMD	Удаление каталога на сервере
PASV	Переход в пассивный режим передачи данных
PORT	Переход в активный режим передачи данных
QUIT	Завершение сеанса работы с FTP-сервером
