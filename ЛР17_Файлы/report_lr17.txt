Задание 1. Настройка виртуальных локальных сетей (VLAN) и access-портов на коммутаторах Cisco.

Виртуальная локальная сеть (VLAN) представляет собой логическую группу сетевых узлов, трафик которых полностью изолирован на канальном уровне модели OSI от других узлов той же физической сети. Порты коммутатора, подключенные к конечным узлам (рабочим станциям пользователей), настраиваются в режим доступа (access port). Порт доступа принадлежит строго одной виртуальной сети и передает кадры без тегов IEEE 802.1Q.

Задание 2. Настройка магистральных каналов (Trunk) и протокола Dynamic Trunk Protocol (DTP).

Магистральный канал (trunk) обеспечивает одновременную передачу мультиплексированного трафика нескольких VLAN по единой физической линии связи между коммутаторами. Для разделения потоков данных используется общепринятый стандарт инкапсуляции IEEE 802.1Q, при котором в каждый передаваемый Ethernet-кадр добавляется 4-байтный тег с идентификатором VLAN ID.

Настройка статического магистрального канала, фильтрация перечня разрешенных VLAN и согласование режимов DTP представлены в листинге 2

Листинг 2 – Настройка статического trunk и фильтрации VLAN на коммутаторе sw1
sw1(config)# interface fa0/22
sw1(config-if)# switchport trunk encapsulation dot1q
sw1(config-if)# switchport mode trunk
sw1(config-if)# switchport trunk allowed vlan 1,2,10,15
sw1(config-if)# switchport trunk native vlan 1
sw1(config-if)# no shutdown
sw1(config-if)# exit

Для автоматического согласования состояния магистрали применяется проприетарный протокол Cisco Dynamic Trunk Protocol (DTP). Он поддерживает режимы switchport mode dynamic auto (пассивный переход в trunk при наличии запроса), switchport mode dynamic desirable (активная регулярная посылка DTP-запросов на поднятие trunk) и switchport nonegotiate (отключение DTP для предотвращения конфликтов с оборудованием сторонних производителей).

Задание 3. Настройка маршрутизации между VLAN (Inter-VLAN Routing) с использованием L3-коммутатора и технологии Router-on-a-Stick.

По умолчанию трафик между различными виртуальными локальными сетями изолирован. Для организации взаимодействия между узлами разных VLAN реализованы два архитектурных подхода:
1. Маршрутизация на коммутаторе 3-го уровня (L3 Switch) с помощью создания виртуальных интерфейсов коммутатора (Switch Virtual Interface, SVI) для каждого VLAN, которые выполняют роль шлюзов по умолчанию, и включения механизма ip routing.
2. Маршрутизация на внешнем маршрутизаторе по технологии «Router-on-a-Stick», при которой физический порт маршрутизатора делится на логические подинтерфейсы (subinterfaces) с привязкой тегов dot1q.

Ответы на контрольные вопросы:

1. Дайте определение access port.
Ответ: Access port (порт доступа) — это коммутационный порт, который принадлежит строго одной виртуальной локальной сети (VLAN) и передает нетегированный информационный трафик. Данный тип порта предназначен для прямого подключения конечных сетевых устройств (рабочих станций, серверов, сетевых принтеров), сетевые карты которых не поддерживают распознавание кадров с тегами IEEE 802.1Q. При передаче исходящего кадра конечному узлу коммутатор удаляет заголовок тега VLAN, а при получении нетегированного кадра от узла маркирует его идентификатором соответствующего access-порта.

2. Дайте определение trunk port.
Ответ: Trunk port (магистральный порт) — это коммутационный порт, посредством которого осуществляется передача мультиплексированного информационного трафика от одного либо нескольких VLAN одновременно по единой физической линии связи. Магистральные порты применяются для межкоммутаторных соединений и подключения коммутаторов к маршрутизаторам. Для идентификации принадлежности Ethernet-кадров к конкретным виртуальным сетям используется механизм инкапсуляции и тегирования по стандарту IEEE 802.1Q (добавление 4-байтового тега с полем VLAN ID), за исключением кадров native VLAN, передаваемых без тегов.

3. Запишите как создать VLAN с идентификатором 7 и именем TEST?
Ответ: Создание виртуальной локальной сети с идентификатором 7 и назначением имени TEST в интерфейсе командной строки Cisco IOS выполняется следующей последовательностью команд:
sw1# configure terminal
sw1(config)# vlan 7
sw1(config-vlan)# name TEST
sw1(config-vlan)# exit

4. Дайте определение и описание Dynamic Trunk Protocol (DTP).
Ответ: Dynamic Trunk Protocol (DTP) — это проприетарный протокол канального уровня компании Cisco, предназначенный для автоматического динамического согласования режима работы сетевого интерфейса (access или trunk) и протокола инкапсуляции (IEEE 802.1Q или ISL) с портом соседнего коммутатора. Протокол включен по умолчанию и осуществляет обмен DTP-кадрами каждые 30 секунд. DTP поддерживает следующие режимы интерфейса:
switchport mode dynamic auto — автоматический пассивный режим, при котором порт готов перейти в trunk, только если соседний порт настроен в режим desirable или trunk;
switchport mode dynamic desirable — активный режим согласования, при котором порт периодически рассылает DTP-кадры и переходит в trunk, если на противоположном конце порт находится в режимах trunk, desirable или auto;
switchport mode trunk — постоянный безусловный перевод порта в магистральный режим trunk независимо от состояния противоположной стороны;
switchport nonegotiate — отключение генерации DTP-кадров на интерфейсе для предотвращения конфликтов и обеспечения совместимости с сетевым оборудованием сторонних производителей при ручной настройке статического trunk.
