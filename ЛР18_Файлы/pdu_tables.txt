Таблица 1 – Структура инкапсуляции и соответствие PDU уровням модели OSI
Уровень модели OSI	Название PDU	Протокол в перехвате	Ключевые поля заголовка	Назначение полей
Канальный (Data Link)	Кадр (Frame)	Ethernet II	Destination MAC, Source MAC, Type	Физическая адресация узлов в локальном сегменте и определение типа вложенного сетевого протокола
Сетевой (Network)	Пакет (Packet)	IPv4	Source IP, Destination IP, TTL, Protocol	Глобальная логическая адресация узлов, маршрутизация и предотвращение зацикливания пакетов
Транспортный (Transport)	Сегмент / Датаграмма	TCP / UDP	Source Port, Destination Port, Seq/Ack, Flags	Адресация процессов (портов) на узлах, мультиплексирование и организация доставки данных
Прикладной (Application)	Сообщение (Data)	HTTP, DNS	Method, URI, Host, User-Agent, Status Code	Передача прикладных запросов, ответов, гипертекста и служебных метаданных сервисов

Таблица 2 – Сравнительный анализ характеристик исследованных протоколов
Параметр сравнения	TCP (Transmission Control Protocol)	UDP (User Datagram Protocol)	HTTP (HyperText Transfer Protocol)
Уровень модели OSI	Транспортный (уровень 4)	Транспортный (уровень 4)	Прикладной (уровень 7)
Название PDU	Сегмент	Датаграмма	Сообщение / Данные
Установление соединения	Обязательное (трехстороннее рукопожатие SYN, SYN-ACK, ACK)	Не требуется (передача без предварительного соединения)	Использует транспортное TCP-соединение
Гарантия доставки	Гарантированная (подтверждения ACK, повторная передача потерь)	Без гарантии доставки и без контроля очередности	Гарантируется транспортным протоколом TCP
Размер заголовка	От 20 до 60 байт (в зависимости от опций)	Фиксированный 8 байт	Переменный (текстовые заголовки запроса и ответа)
Скорость передачи	Умеренная из-за служебных накладных расходов	Максимальная скорость с минимальными задержками	Зависит от размера передаваемого контента
Сфера применения	Веб-страницы (HTTP/HTTPS), файлы (FTP), почта (SMTP)	Потоковое видео/аудио, VoIP, онлайн-игры, DNS	Передача веб-страниц, REST API, веб-сервисы
