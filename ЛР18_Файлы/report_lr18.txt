Рисунок 2 – Перехват сетевого трафика и структура инкапсуляции PDU в программе Wireshark

При детальном исследовании захваченного пакета №6 (HTTP GET) в информационном поле Wireshark проанализирована многоуровневая структура инкапсуляции протокольных блоков данных (Protocol Data Unit, PDU):
Канальный уровень (Data Link): блок данных кадр (Frame, Ethernet II), содержит физические MAC-адреса узлов источника и назначения, а также код инкапсулированного сетевого протокола (Type: IPv4 0x0800).
Сетевой уровень (Network): блок данных пакет (Packet, Internet Protocol Version 4), обеспечивает логическую адресацию узлов (IP-адреса отправителя 192.168.1.105 и получателя 93.184.216.34), содержит время жизни пакета (TTL) и тип инкапсулированного транспортного протокола (Protocol: TCP 6).
Транспортный уровень (Transport): блок данных сегмент (Segment, Transmission Control Protocol), организует адресацию процессов на конечных узлах через номера портов (Source Port: 54128, Destination Port: 80), управление порядком и надежностью доставки.
Прикладной уровень (Application): блок данных сообщение/данные (Data, Hypertext Transfer Protocol), содержит прикладной запрос клиента на передачу веб-ресурса.

Ответы на контрольные вопросы:

1. Дайте определение протоколу IP.
Ответ: IP (Internet Protocol) – это сетевой протокол семейства TCP/IP, обеспечивающий глобальную логическую адресацию узлов и маршрутизацию дейтаграмм в составных сетях без установления предварительного соединения и без гарантированной доставки.

2. Дайте определение протоколу TCP.
Ответ: TCP (Transmission Control Protocol) – это надежный протокол транспортного уровня, обеспечивающий дуплексную передачу потока данных с предварительным установлением логического соединения (трехстороннее рукопожатие), гарантированной доставкой за счет подтверждений (ACK), контролем порядка следования пакетов и механизмом управления потоком данных.

3. Дайте определение протоколу UDP.
Ответ: UDP (User Datagram Protocol) – это легковесный протокол транспортного уровня, передающий данные независимыми датаграммами без предварительного установления соединения, без подтверждения доставки и без контроля очередности пакетов, что минимизирует накладные расходы и задержки передачи.

4. Дайте определение протоколу HTTP(S).
Ответ: HTTP (HyperText Transfer Protocol) и его защищенная криптографическим протоколом TLS/SSL версия HTTPS – это прикладной протокол передачи гипертекстовых документов и произвольных данных, функционирующий по клиент-серверной архитектуре на основе модели «запрос-ответ».

5. Дайте определение протоколу FTP(S).
Ответ: FTP (File Transfer Protocol) и защищенный вариант FTPS – это прикладной протокол передачи файлов между узлами вычислительной сети, архитектурной особенностью которого является разделение взаимодействия на два независимых TCP-соединения: канал управления (порт 21) для команд и аутентификации и канал данных (порт 20) для непосредственной передачи файлов.
