2	C	9.6%	Разработан в 1972 году Деннисом Ритчи в Bell Labs для написания ОС Unix на замену языку B. Стандартизирован ANSI в 1989 году (C89). 3	C++	9.2%	Создан в 1979 году Бьёрном Страуструпом как «C с классами». В 1983 году переименован в C++. Стандарты: C++98, C++11, C++20, C++23.	Игровые 3D-движки (GameDev), высокопроизводительные системы, высокочастотный трейдинг (HFT), обработка графики.	Разработчики AAA-игр, системные и графические инженеры, квант-разработчики. 4	Java	8.7%	Создан в 1995 году Джеймсом Гослингом в Sun Microsystems (ныне Oracle) по принципу «Write Once, Run Anywhere» (WORA) на базе JVM. Apache Kafka, Apache Hadoop, Apache Spark, банковские системы (Сбер, Тинькофф), игра Minecraft, IntelliJ IDEA.
5	C#	6.8%	Создан в 2000 году Андерсом Хейлсбергом в корпорации Microsoft под платформу .NET. С 2014 года открытый кроссплатформенный .NET Core.	Корпоративные серверные сервисы, веб-приложения ASP.NET Core, разработка 2D/3D-игр на Unity, Windows-десктоп.	Корпоративные разработчики, создатели игр на движке Unity, fullstack-инженеры стека Microsoft. 6	JavaScript	3.4%	Создан в 1995 году Бренданом Эйхом в компании Netscape за 10 дней. В 2009 году создан рантайм Node.js для исполнения JS на сервере.	Клиентская веб-разработка (Frontend), серверные микросервисы (Node.js), кроссплатформенный десктоп (Electron).	Frontend-, backend- и fullstack-веб-разработчики, дизайнеры интерактивных интерфейсов.	Мессенджер Discord, редактор Visual Studio Code, интерфейсы ВКонтакте, Telegram Web, Skype, Slack.
7	Go	2.4%	Разработан в 2007 году в Google Робертом Гризмером, Робом Пайком и Кеном Томпсоном. Релиз Go 1.0 состоялся в 2012 году.	Облачная инфраструктура, микросервисы, высоконагруженные сетевые API, инструменты DevOps и контейнеризации.	Инженеры облачных платформ, бэкенд-разработчики микросервисов, DevOps-инженеры.	Платформа Docker, оркестратор Kubernetes, система мониторинга Prometheus, утилита Terraform, сервисы Google и Ozon.
8	SQL	2.1%	Разработан в начале 1970-х в IBM Эдгаром Коддом, Дональдом Чэмберлином и Рэймондом Бойсом. Стандартизирован ANSI в 1986 году.	Создание, модификация, структурирование и выборка данных в реляционных базах данных, построение аналитики.	Администраторы баз данных (DBA), аналитики данных, бэкенд-разработчики, BI-инженеры. 9	Rust	1.8%	Зародился в 2006 году как личный проект Грейдона Хора (Mozilla). Релиз Rust 1.0 в 2015 году. Концепция безопасной работы с памятью.	Системное ПО, критически важные компоненты ОС, блокчейн-платформы, высокопроизводительные сетевые сервисы.	Системные программисты, разработчики криптографии и безопасности, бывшие C/C++ специалисты. Серверная веб-разработка, системы управления контентом (CMS), интернет-магазины, порталы электронной коммерции.	Веб-разработчики бэкенда, веб-мастера CMS, разработчики интернет-магазинов, фрилансеры.
