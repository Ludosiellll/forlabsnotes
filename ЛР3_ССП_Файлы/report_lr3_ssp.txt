2.1. Нахождение минимального среди трех чисел (Приложение А, Вариант 6)
Для варианта 6 разработана программа, запрашивающая у пользователя три числа с клавиатуры и определяющая наименьшее из них с помощью условного оператора if-else.

Код разработанной программы нахождения минимального числа представлен в листинге 1

Листинг 1 – Исходный код программы Task1_MinOfThree.java
import java.util.Scanner;

public class Task1_MinOfThree {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Введите первое число: ");
        double a = scanner.nextDouble();

        System.out.print("Введите второе число: ");
        double b = scanner.nextDouble();

        System.out.print("Введите третье число: ");
        double c = scanner.nextDouble();

        double min;
        if (a <= b && a <= c) {
            min = a;
        } else if (b <= a && b <= c) {
            min = b;
        } else {
            min = c;
        }

        System.out.println("Минимальное число: " + min);

        scanner.close();
    }
}

    public static void main(String[] args) {
        for (int i = 90; i >= 0; i -= 5) {
            System.out.print(i + " ");
        }
        System.out.println();
    }

2.3*. Проверка геометрического размещения прямоугольников (Приложение С, Задание 2)
Разработана программа для анализа возможности размещения прямоугольника со сторонами a, b внутри внешнего прямоугольника со сторонами c, d. Проверяются условия параллельного размещения (a <= c и b <= d) и размещения с поворотом на 90 градусов (a <= d и b <= c).

Код разработанной программы проверки размещения прямоугольников представлен в листинге 3

Листинг 3 – Исходный код программы Task3_Rectangles.java
import java.util.Scanner;

public class Task3_Rectangles {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Введите сторону a: ");
        double a = scanner.nextDouble();
        System.out.print("Введите сторону b: ");
        double b = scanner.nextDouble();

        System.out.print("Введите сторону c: ");
        double c = scanner.nextDouble();
        System.out.print("Введите сторону d: ");
        double d = scanner.nextDouble();

        if (a <= 0 || b <= 0 || c <= 0 || d <= 0) {
            System.out.println("Стороны должны быть положительными");
            scanner.close();
            return;
        }

        if ((a <= c && b <= d) || (a <= d && b <= c)) {
            System.out.println("Прямоугольник помещается");
        } else {
            System.out.println("Прямоугольник не помещается");
        }

        scanner.close();
    }
}

Ответы на контрольные вопросы:

1. Какие основные условные конструкции существуют в языке Java?
Ответ: В языке Java применяются условный оператор ветвления if-else (выполняет соответствующий блок команд в зависимости от истинности булевого выражения), оператор многовариантного выбора switch-case (сопоставляет значение переменной или выражения с константными метками case) и тернарный условный оператор (условие ? выражение1 : выражение2), возвращающий результат одного из выражений.

2. Что выведет следующий фрагмент кода:
int x = 3;
int y = 2;
System.out.println(x < y ? x + y : x - y);
Ответ: Фрагмент кода выведет значение 1, поскольку условие x < y (3 < 2) возвращает значение false, в результате чего вычисляется и выводится выражение после двоеточия: x - y = 3 - 2 = 1.

3. Что выведет следующая программа:
int a = 5;
switch (a) {
    case 1: a++;
    case 5: a++;
    case 6: a++;
    case 7: a++;
    case 8: a++; break;
    case 9: a++;
    default: a++;
}
System.out.println(a);
Ответ: Программа выведет значение 9. При a = 5 управление передается метке case 5, где переменная инкрементируется до 6. Так как оператор break в ветках case 5, case 6 и case 7 отсутствует, происходит сквозное выполнение (fall-through): в case 6 значение увеличивается до 7, в case 7 — до 8, в case 8 — до 9, после чего оператор break прерывает конструкцию switch.

4. Назовите основные циклы в языке Java и опишите различия между ними.
Ответ: В Java выделяют цикл for (цикл со счетчиком, применяемый при известном числе итераций), цикл while (цикл с предусловием, где тело может не выполниться ни разу, если начальное условие ложно), цикл do-while (цикл с постусловием, гарантирующий как минимум однократное выполнение тела цикла до проверки условия) и расширенный цикл for-each (для последовательного обхода элементов массивов и коллекций).

5. Сколько раз выполнится цикл:
int i = 5;
while (i > 0) {
    i = i * 3 * (-2);
}
Ответ: Цикл выполнится ровно 1 раз. При первой проверке условие i > 0 (5 > 0) истинно, внутри цикла переменная принимает значение 5 * 3 * (-2) = -30, и при следующей проверке условие -30 > 0 возвращает false, завершая выполнение цикла.
