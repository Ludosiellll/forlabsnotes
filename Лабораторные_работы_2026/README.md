## Как открыть

- **PDF** — открывается прямо в браузере на GitHub по ссылке из таблицы; для скачивания — кнопка *Download* на странице файла.
- **DOCX** — GitHub показывает превью документа; полный вид и скачивание доступны по кнопке *Download*.

Скачать всю папку целиком:

```bash
git clone https://github.com/Ludosiellll/forlabsnotes.git
```

## Пояснение к именам

Имена файлов сохранены как есть, включая дисциплину и номер работы.
`ССП` / `ПССИП` — самостоятельная и программно-аппаратная часть разработки информационных систем,
`КМС` — компьютерные методы счисления, «Тест ПО» — тестирование программного обеспечения.
