В ходе выполнения задания реализованы следующие структурные и стилистические элементы:
1. Оформление фона страниц: на главной странице index.html продемонстрирована установка фонового цвета через атрибут bgcolor="#f4f7f6", а на странице sights.html выполнена установка графического фонового рисунка через атрибут background="bg_pattern.png".
2. Оформление верхней части страниц: внедрена горизонтальная линия разметки тегом <hr width="90%" size="4" color="#1a5276" align="center"> с явным заданием ширины, толщины, цвета и выравнивания.
3. Навигационное меню: создана панель перехода по внутренним закладкам-якорям (#about, #districts, #history, #symbols, #media, #developer) и межстраничной навигации.
4. Создание списков: использованы все три вида списков — маркированный <ul type="square"> для административных районов города с вложенным списком <ul type="circle">, нумерованный <ol type="1"> с атрибутом value для хронологии исторических вех, а также список определений <dl> с тегами терминов <dt> и описаний <dd> для геральдических символов города.
5. Вставка ссылок: организованы текстовые гиперссылки, ссылки на якоря внутри документа, внешняя ссылка на официальный интернет-портал города bobruisk.by с атрибутом target="_blank", а также ссылка с графическим элементом привязки (изображение памятника Бобру и герб города выступают кликабельными ссылками).
6. Вставка графических объектов: применены изображения герба города, памятника Бобру, Бобруйской крепости и фото разработчика с атрибутами src, alt, title, border, align, width, height, hspace, vspace.
7. Внедрение мультимедиа: интегрирован аудиофрагмент через тег <audio controls src="audio_bobruisk.wav"> и видеоролик через тег <video controls poster="video_poster.jpg" src="bobruisk_video.mp4">.
8. Создание таблиц: сформирована таблица достопримечательностей с объединением ячеек по горизонтали (colspan) и вертикали (rowspan), а также создана Карточка разработчика по установленной форме таблицы 4 методических указаний.

Ответы на контрольные вопросы:

1. Как объявить ссылку перехода с одной страницы на другую?
Ответ: С помощью парного тега <a href="путь_к_странице">текст ссылки</a>, указав в атрибуте href имя файла или URL целевого документа.

2. Как добавить изображение в HTML документ?
Ответ: С помощью одиночного тега <img src="путь_к_файлу" alt="описание">, где в обязательном атрибуте src прописывается путь к графическому файлу.

3. Для чего используются теги <div>, <span>?
Ответ: Тег <div> служит универсальным блочным контейнером для группировки крупных элементов разметки, а тег <span> — строчным контейнером для стилевого выделения фрагментов текста внутри строки.

4. Какие бывают списки? Описать их характеристики.
Ответ: Маркированные <ul> (пункты выделяются графическими маркерами), нумерованные <ol> (пункты упорядочены цифрами или буквами) и списки определений <dl> (содержат пары из термина <dt> и его пояснения <dd>).

5. Создание таблиц в HTML.
Ответ: Таблица создается парным тегом <table>, строки определяются тегами <tr>, а ячейки — тегами <td> (или <th> для шапки), с возможностью объединения атрибутами colspan и rowspan.
