Задание 1. Создание формы авторизации пользователя на веб-сайте.

В рамках проекта краеведческого портала города Бобруйска (вариант 14) разработан документ login.html, содержащий простую форму авторизации пользователей. 

Форма создана с помощью парного контейнера <form action="/login" method="post">. Для ввода данных применены элементы <input>: текстовое поле с атрибутом type="text" для ввода имени пользователя (логина) и защищенное поле с атрибутом type="password" для ввода секретного пароля, в котором вводимые символы маскируются точками. Для удобства пользователей задействованы атрибуты placeholder с поясняющими подсказками, required для обязательного заполнения полей и autofocus для автоматической установки фокуса при загрузке. Отправка введенных данных осуществляется кнопкой <button type="submit"> с надписью «Войти».

Задание 2. Создание формы регистрации с интеграцией и сохранением учетных записей в базе данных.

Создан документ register.html для регистрации новых пользователей портала. Форма включает в себя обязательные поля ввода имени (first_name), фамилии (last_name), адреса электронной почты с типом input type="email" (обеспечивающим базовую валидацию синтаксиса e-mail в браузере), а также пароля и подтверждения пароля (input type="password" с минимальной длиной minlength="6").

Для выполнения требования сохранения данных в базе данных разработан серверный обработчик на языке Python (server.py) со встроенной реляционной СУБД SQLite3. При нажатии кнопки «Зарегистрироваться» форма методом POST передает параметры на адрес обработчика /register. Сервер производит безопасное криптографическое хэширование пароля алгоритмом SHA-256 и выполняет SQL-запрос INSERT INTO users для добавления записи в таблицу users базы данных users.db.

Код серверного обработчика сохранения в базе данных server.py представлен в листинге 3

Листинг 3 – Исходный код серверного обработчика server.py
import sqlite3, hashlib
from datetime import datetime

def register_user(first_name, last_name, email, password):
    conn = sqlite3.connect("users.db")
    cursor = conn.cursor()
    cursor.execute("""
        CREATE TABLE IF NOT EXISTS users (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            first_name TEXT NOT NULL,
            last_name TEXT NOT NULL,
            email TEXT UNIQUE NOT NULL,
            password_hash TEXT NOT NULL,
            created_at DATETIME DEFAULT CURRENT_TIMESTAMP
        )
    """)
    pwd_hash = hashlib.sha256(password.encode('utf-8')).hexdigest()
    cursor.execute("""
        INSERT INTO users (first_name, last_name, email, password_hash)
        VALUES (?, ?, ?, ?)
    """, (first_name, last_name, email, pwd_hash))
    conn.commit()
    user_id = cursor.lastrowid
    conn.close()
    return user_id

Задание 3. Создание комплексной формы-тестирования по тематике города Бобруйска с использованием всех типов элементов форм.

Создан документ test.html, реализующий электронное тестирование на тему «История и культура города Бобруйска». Для соответствия методическим указаниям форма охватывает все предусмотренные стандартом HTML5 элементы и модификации атрибутов:
1. Контейнер <form> с атрибутами method="post", action="/test_submit", enctype="multipart/form-data".
2. Текстовые элементы ввода: однострочный текст (type="text" с атрибутами placeholder, maxlength, value), поле пароля (type="password"), электронная почта (type="email"), телефон (type="tel" с валидацией по маске pattern="\+375[0-9]{9}"), ссылка на веб-ресурс (type="url"), а также скрытое поле (type="hidden") для передачи номера варианта 14.
3. Поля даты и времени: дата (type="date"), время (type="time"), совмещенное поле (type="datetime-local"), выбор месяца (type="month") и недели (type="week").

5. Числовые и интервальные поля: числовой ввод (type="number" с атрибутами min, max, step для указания года основания города), ползунок шкалы оценивания (type="range").
6. Специальные элементы интерфейса: выпадающий список <select> с пунктами <option> для выбора административного района, многострочное текстовое поле <textarea> для развернутого исторического комментария, поле выбора локального файла (type="file"), палитра выбора цвета оформления (type="color"), а также поле только для чтения с атрибутом readonly.
7. Все разновидности кнопок: кнопка отправки данных (<button type="submit">), кнопка сброса полей (<button type="reset">), пользовательская кнопка (<button type="button"> с JavaScript-обработчиком вывода подсказки), а также графическая кнопка отправки в виде изображения (<input type="image" src="btn_submit.png">).

Ответы на контрольные вопросы:

1. Какие элементы используются для объявления формы?
Ответ: Парный тег <form> и закрывающий тег </form>.

2. Какие элементы используются для задания элементов в форме?
Ответ: Теги <input>, <button>, <select>, <option>, <textarea>, <label>, <fieldset>, <legend>.

3. Какие методы можно применять для отправки данных формы?
Ответ: Метод GET (передача данных через строку параметров URL-адреса) и метод POST (передача данных внутри тела HTTP-запроса).

4. Какие теги используются для создания текстовых полей ввода в форме?
Ответ: Одиночный тег <input> (с атрибутами type="text", type="password", type="email", type="tel", type="url", type="number") для однострочного ввода и парный тег <textarea> для многострочного текста.

5. С помощью какого атрибута элемента FORM указывается адрес, по которому нужно отправлять данные формы?
Ответ: С помощью обязательного атрибута action.
