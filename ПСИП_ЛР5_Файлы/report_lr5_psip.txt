Задание 2. На странице, где расположено изображение и текст, используйте свойство CSS position в сочетании с top, bottom, left и right для точного позиционирования элементов
В рамках второго задания разработан веб-документ positioning.html, в котором реализовано точное позиционирование текстовых и графических элементов поверх полноразмерного изображения памятника Бобру.
Для решения задачи применены различные значения свойства CSS position:
position: relative задано для родительского арт-контейнера .showcase-card, что сформировало собственную локальную систему координат для дочерних абсолютно позиционированных элементов без их выбивания из нормального потока страницы;
position: absolute в сочетании с координатами top: 18px и left: 18px применено для неонового бейджа категории памятника с точкой-индикатором;
position: absolute в сочетании с координатами top: 18px и right: 18px использовано для золотистой плашки рейтинга достопримечательности;
position: absolute с координатами top: 42% и left: 51% применено для интерактивного гео-пина с пульсирующим радиусным кольцом и выводом точных географических координат объекта;
position: absolute с одновременным заданием bottom: 0, left: 0 и right: 0 применено для полупрозрачной оверлей-панели с градиентным затемнением, тегами характеристик и исторической справкой в нижней части изображения;
position: fixed в сочетании с bottom: 24px и right: 24px применено для плавающей неоновой кнопки быстрого возврата на главную страницу, которая остается зафиксированной в правом нижнем углу окна браузера при любой прокрутке.

Ответы на контрольные вопросы:

1. Правила каскадности. Примеры?
Ответ: Каскадность — алгоритм разрешения конфликтов при совпадении стилей для элемента. Приоритет определяется по трем правилам: важность (!important), специфичность селектора (строковый style > id > класс > тег) и порядок объявления (при равной специфичности побеждает объявленный позже). Пример: для элемента с классом и id стиль по #id переопределит стиль по .class.

2. Разновидности web-дизайнов их достоинства и недостатки (текстовый, фреймовый, табличный, контейнерный)?
Ответ: Сравнительная характеристика разновидностей web-дизайнов приведена ниже:
Текстовый дизайн отличается максимальной простотой и минимальным весом, но не имеет визуальной структуры и оформления.
Фреймовый дизайн позволяет независимо прокручивать и обновлять части окна, но плохо индексируется поисковыми системами и создает трудности при печати и закладках.
Табличный дизайн обеспечивает жесткую и надежную сетку размещения блоков, но приводит к громоздкому коду и медленной отрисовке браузером.
Контейнерный дизайн (блочный на div, Flexbox, CSS Grid) обеспечивает разделение структуры и оформления, высокую скорость загрузки и гибкую адаптивность, но требует глубоких знаний возможностей CSS.

3. Что такое контейнеры?
Ответ: Контейнеры — элементы HTML-разметки, предназначенные для выделения, объединения и группировки фрагментов страницы без навязывания собственного визуального оформления. Они служат для привязки стилей CSS и скриптов поведения. Делятся на блочные (тег <div>, создающий перенос строки) и встроенные (тег <span>, выделяющий фрагмент внутри строки).

4. Виды селекторов CSS?
Ответ: Выделяют следующие виды: простые селекторы тегов (p, h1), классов (.name) и идентификаторов (#id); универсальный селектор (*); селекторы атрибутов ([type="text"]); комбинаторы (потомки div p, дочерние ul > li, смежные h1 + p); псевдоклассы (:hover, :active, :first-child, :nth-child) и псевдоэлементы (::before, ::after, ::first-letter).
