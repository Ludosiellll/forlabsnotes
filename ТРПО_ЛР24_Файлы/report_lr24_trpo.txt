Задание 1. Построить прототипы программного обеспечения по описаниям вариантов использования

1.1. Описание вариантов использования системы
На основе анализа предметной области детского развивающего мобильного приложения «БыстрУм» выделены три основных варианта использования (прецедента):
- прецедент 1 «Выбор и запуск развивающей мини-игры»: ребенок в главном меню просматривает доступные развивающие активности («Математический спринт», «Поиск лишнего», «Логические пары»), выбирает подходящую мини-игру и запускает сеанс; программа обеспечивает игровой процесс в индивидуальном темпе без стрессового фактора времени;
- прецедент 2 «Просмотр коллекции наград и кубков»: ребенок переходит на экран достижений, просматривает заработанные и предстоящие награды, мотивируется поддерживающим сообщением («Ты учишься и растёшь! Играй в своём темпе. Новые кубки подождут.»);
- прецедент 3 «Настройка параметров доступности родителем»: родитель переходит в экран настроек, регулирует звуковое сопровождение, включает спокойный режим (уменьшение анимации, игра без таймера) и выбирает допустимую продолжительность занятия (5, 10, 15 или 20 минут) с напоминанием о перерыве.

Задание 2. Закодировать основные модули системы

2.1. Программная реализация основных модулей
Для обеспечения работоспособности прототипа на языке C# в среде Visual Studio разработаны ключевые программные классы:
- класс ChildProfile: инкапсулирует данные учетной записи ребенка (Nickname, Age, Level, StarsCount, ExperiencePoints) и метод начисления наград AddRewards;
- класс AccessibilitySettings: управляет флагами доступности (GameSoundsEnabled, BackgroundMusicEnabled, ReduceMotion, PlayWithoutTimer, SessionDurationMinutes, BreakReminderEnabled);
- класс AchievementService: реализует хранилище наград по трем направлениям мини-игр с возможностью их программной разблокировки Unlock;
- класс GameEngine: моделирует раунд мини-игры «Математический спринт» с учетом режима PlayWithoutTimer и фиксацией времени реакции;
- класс Program: демонстрирует интеграцию всех модулей в единый рабочий сценарий.

Программный код реализации основных модулей прототипа приложения приведен в листинге 1
Листинг 1 – Программный код реализации основных модулей прототипа приложения
using System;
using System.Collections.Generic;

namespace BystrUmApp
{
    public class ChildProfile
    {
        public string Nickname { get; set; } = "Артём";
        public int Age { get; set; } = 6;
        public int Level { get; set; } = 3;
        public int StarsCount { get; set; } = 14;
        public int ExperiencePoints { get; set; } = 360;

        public void AddRewards(int stars, int xp)
        {
            StarsCount += stars;
            ExperiencePoints += xp;
            if (ExperiencePoints >= Level * 150)
            {
                Level++;
            }
        }

        public void DisplayProfileInfo()
        {
            Console.WriteLine($"[Профиль игрока]: {Nickname}, {Age} лет | Уровень: {Level} | Звёзды: ★ {StarsCount} | Опыт: {ExperiencePoints} XP");
        }
    }

    public class AccessibilitySettings
    {
        public bool GameSoundsEnabled { get; set; } = true;
        public bool BackgroundMusicEnabled { get; set; } = false;
        public bool ReduceMotion { get; set; } = true;
        public bool PlayWithoutTimer { get; set; } = true;
        public int SessionDurationMinutes { get; set; } = 15;
        public bool BreakReminderEnabled { get; set; } = true;

        public void DisplaySettings()
        {
            Console.WriteLine("--- Родительские настройки доступности ---");
            Console.WriteLine($"Звуки игры: {(GameSoundsEnabled ? "Включены (мягкие звуки)" : "Выключены")}");
            Console.WriteLine($"Фоновая музыка: {(BackgroundMusicEnabled ? "Включена" : "Выключена (игра в тишине)")}");
            Console.WriteLine($"Спокойный режим (уменьшить анимацию): {(ReduceMotion ? "Включено" : "Выключено")}");
            Console.WriteLine($"Игра без таймера: {(PlayWithoutTimer ? "Включено (без ограничений)" : "Выключено (с таймером)")}");
            Console.WriteLine($"Длительность занятия: {SessionDurationMinutes} мин | Напоминать о перерыве: {(BreakReminderEnabled ? "Да" : "Нет")}");
        }
    }

    public class Achievement
    {
        public string Title { get; set; } = string.Empty;
        public string Description { get; set; } = string.Empty;
        public string Category { get; set; } = string.Empty;
        public bool IsUnlocked { get; set; }

        public Achievement(string title, string description, string category, bool isUnlocked)
        {
            Title = title;
            Description = description;
            Category = category;
            IsUnlocked = isUnlocked;
        }
    }

    public class AchievementService
    {
        private readonly List<Achievement> _achievements = new();

        public AchievementService()
        {
            _achievements.Add(new Achievement("Друг чисел", "За 1 игру с числами", "Математический спринт", true));
            _achievements.Add(new Achievement("Кубок счёта", "За 5 игр с числами", "Математический спринт", false));
            _achievements.Add(new Achievement("Зоркий глаз", "За 1 игру на поиск", "Поиск лишнего", true));
            _achievements.Add(new Achievement("Кубок внимания", "За 5 игр на поиск", "Поиск лишнего", false));
            _achievements.Add(new Achievement("Первые пары", "За 1 игру с парами", "Логические пары", true));
            _achievements.Add(new Achievement("Кубок логики", "За 5 игр с парами", "Логические пары", false));
        }

        public void Unlock(string title)
        {
            var ach = _achievements.Find(a => a.Title == title);
            if (ach != null && !ach.IsUnlocked)
            {
                ach.IsUnlocked = true;
                Console.WriteLine($"[НОВАЯ НАГРАДА РАЗБЛОКИРОВАНА]: {ach.Title} ({ach.Category})");
            }
        }

        public void DisplayCollection()
        {
            Console.WriteLine("--- Мои достижения и кубки ---");
            Console.WriteLine("«Ты учишься и растёшь! Играй в своём темпе. Новые кубки подождут.»");
            foreach (var item in _achievements)
            {
                string status = item.IsUnlocked ? "[✓ Получено]" : "[Впереди]";
                Console.WriteLine($"  {status} {item.Title} ({item.Category}): {item.Description}");
            }
        }
    }

    public class GameSessionResult
    {
        public string GameTitle { get; set; } = string.Empty;
        public int TotalTasks { get; set; }
        public int CorrectAnswers { get; set; }
        public double AverageReactionTimeMs { get; set; }
        public int EarnedStars { get; set; }
        public int EarnedXP { get; set; }
    }

    public class GameEngine
    {
        public GameSessionResult PlayMathSprint(AccessibilitySettings settings)
        {
            Console.WriteLine("
[Запуск мини-игры]: Математический спринт (Играй с числами)");
            if (settings.PlayWithoutTimer)
            {
                Console.WriteLine("Режим: Без таймера (комфортный темп для ребенка)");
            }

            int tasksCount = 3;
            int correct = 3;
            double reactionMs = 760.0;

            Console.WriteLine($"Выполнено заданий: {tasksCount}/{tasksCount}");
            Console.WriteLine($"Точность: 100% | Зафиксированная скорость реакции: {reactionMs:F0} мс");

            return new GameSessionResult
            {
                GameTitle = "Математический спринт",
                TotalTasks = tasksCount,
                CorrectAnswers = correct,
                AverageReactionTimeMs = reactionMs,
                EarnedStars = 3,
                EarnedXP = 50
            };
        }
    }

    class Program
    {
        static void Main()
        {
            Console.OutputEncoding = System.Text.Encoding.UTF8;
            Console.WriteLine("=== Прототип программной системы «БыстрУм» ===");

            var profile = new ChildProfile();
            var settings = new AccessibilitySettings();
            var achievements = new AchievementService();
            var engine = new GameEngine();

            profile.DisplayProfileInfo();
            Console.WriteLine();
            settings.DisplaySettings();
            Console.WriteLine();
            achievements.DisplayCollection();

            var session = engine.PlayMathSprint(settings);

            profile.AddRewards(session.EarnedStars, session.EarnedXP);
            achievements.Unlock("Кубок счёта");

            Console.WriteLine("
--- Итоги раунда ---");
            Console.WriteLine($"Получено звёзд: +{session.EarnedStars} ★ | Опыт: +{session.EarnedXP} XP");
            profile.DisplayProfileInfo();
        }
    }
}

Задание 4. Подготовить рекомендации по исправлению выявленных нарушений

4.1. Рекомендации по оптимизации интерфейса
На основе анализа выявленных замечаний сформированы следующие рекомендации по модернизации интерфейса:
- внедрение родительского защитного барьера (Parental Gate): добавить контрольное математическое действие (например, «Решите пример 2 + 3») перед открытием экрана «Родительские настройки» для предотвращения несанкционированного изменения параметров ребенком;
- добавление тактильного виброотклика (Haptic Feedback): настроить мягкую вибрацию устройства при переключении тумблеров и выборе карточек для дополнительного сенсорного подкрепления у детей с расстройствами внимания;
- голосовое озвучивание текста (Text-to-Speech): предусмотреть кнопку голосового воспроизведения названий заданий и наград для детей в возрасте 4–5 лет, еще не овладевших устойчивым навыком самостоятельного чтения;
- визуализация тайм-менеджмента: дополнить числовые чипы длительности занятия (5, 10, 15, 20 минут) наглядной круговой диаграммой или песочными часами для более легкого восприятия времени ребенком;
- режим повышенного контраста: предусмотреть альтернативную высококонтрастную палитру для пользователей с тяжелыми нарушениями цветовосприятия.
